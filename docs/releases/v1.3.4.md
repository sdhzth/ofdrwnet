# NetOfd v1.3.4

## 补丁版本：修正 NuGet 包页面的「当前版本」标注，补齐 v1.3.3 发布说明

本次为**补丁版本（patch）**，**零代码改动**，只修正文档索引。

### 🐛 修复：NuGet 包页面「发布说明」索引停留在 v1.3.2

**现象**：nuget.org 上 `NetOfd.*` 各包的包页面直接渲染**包内的 README 副本**，其中
「发布说明」表格把 `v1.3.2` 标为「当前」，而实际最新版本已是 v1.3.3 —— 包页面与实际版本对不上。

**根因**：README 的发布说明索引把「当前版本」**写死**为字符串，发布新版本时没有随之更新；
且 v1.3.3 缺少对应的发布说明文件（`docs/releases/v1.3.3.md` / `v1.3.3.en.md`）。

**修复**：

1. README（中 / 英）的发布说明索引「当前版本」更新为 v1.3.4，并补上 v1.3.3、v1.3.2 两行；
2. 补齐 `docs/releases/v1.3.3.md` 与 `docs/releases/v1.3.3.en.md`，内容涵盖 v1.3.3 的三大主题：
   - **`defaults` 命名空间合规** —— GB/T 33190-2016 §7.1 / GB/T 48666-2026 §6.2 要求根节点
     额外声明 `xmlns:defaults`；新增 `OFDElement.InjectDefaultsDeclaration*` /
     `RestoreOfdPrefix*` / `NormalizeOfdXmlBytes`，废弃 `EnsureDefaultsNamespace(XElement)`
     （LINQ-to-XML 无法表达同命名空间双前缀，会把元素前缀 `ofd:` 改写成 `defaults:`，违反 §7.1）；
   - **页面级资源 `PageRes.xml` 读写双向支持** —— GB/T 48666-2026 §7.2 a；Reader 侧补齐 Java 版
     缺失的第三类资源，生成侧新增 `MediaPlacement.Auto` / `DocumentOnly`，
     `PageObject.AddPageRes` 保证 `PageRes` 排在 `Content` 之前（GB/T 33190 表 13 Schema 顺序）；
   - **字型资源规范命名 `Font_M.ttf`** —— GB/T 48666-2026 表 1。

> **为什么不能就地修 1.3.3**：包内 README 是**已发布版本的固化副本**，NuGet 不允许覆盖已发布
> 版本，因此该修正只能随下一个版本（本次 v1.3.4）发布才会体现在包页面上。
